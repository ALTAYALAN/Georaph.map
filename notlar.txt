🏛️ PART 1: Lokanta Analojisi ile Ne İsteniyor?
Yönergeler sizden tam teşekküllü bir Harita Web Uygulaması yapmanızı istiyor:

[ React (Frontend) ]  <--- (İstek/Cevap) --->  [ .NET 8 Web API (Backend) ]  <--- (SQL) --->  [ PostgreSQL + PostGIS (Veritabanı) ]
 (Kullanıcı Arayüzü)                             (Mutfak / Garson / Mantık)                    (Malzeme Deposu)
PostgreSQL + PostGIS Kurun (Depo/Kiler):
PostgreSQL: Bilgileri (isimler, tarihler) saklayan bir veritabanıdır.
PostGIS Eklentisi: Normal veritabanı harita koordinatlarından (enlem, boylam) anlamaz. PostGIS, veritabanına "Harita & Coğrafya Zekası" kazandıran bir eklentidir. "Şu noktaya 5 km yakınlıktaki yerleri bul" gibi harita sorgularını yapabilmesini sağlar.
NET 8 ile Web API Oluşturun (Mutfak & Garson):
İnternet sitesinin görünmeyen arka planı (Backend). Dışarıdan gelen verileri alır, kontrol eder ve veritabanına kaydeder.
Katmanlı Mimariye Uygun Düzenleyin (Mutfaktaki Görev Dağılımı):
Tüm kodları tek bir çuvala doldurmak yerine işleri bölüşmektir:
Core (Çekirdek): Kurallar ve şablonlar (Mekan nesnesi nedir, neleri vardır?).
Infrastructure (Altyapı): Veritabanı ile konuşan aşçı (Veritabanına kaydet, sil, getir).
API: Müşteriyle konuşan garson (İstekleri karşılar, aşçıya iletir).
Controller Yazarak Veritabanına Erişim Sağlayın (Garson Masası):
Dış dünyadan gelen "Bana mekanları getir" veya "Yeni mekan ekle" çağrılarını karşılayan koddur.
POST İsteği Atarak Veri Yazdığınızı Görün (Sipariş Verme):
GET: Veri okumak/getirmek demektir.
POST: Yeni veri göndermek/kaydetmek demektir.
Swagger veya Postman kullanarak "Yeni Mekan: Kadıköy Meydanı, Enlem: 40.9, Boylam: 29.0" bilgisini API'ye gönderip veritabanına kaydolduğunu teyit etmeniz isteniyor.
React ile Frontend Oluşturun (Müşteri Masası & Menü):
Kullanıcının ekranda göreceği butonlar, haritalar ve formların olduğu web arayüzüdür.
📁 PART 2: Mevcut Projenizdeki Dosyalar Ne İşe Yarıyor?
Şu an bilgisayarınızdaki klasörde bulunan dosyaların işlevleri:

1. 

GeoMap.slnx
 (Solution Dosyası)
Bütün alt projeleri (API, Core, Infrastructure) bir arada tutan ana klasör haritasıdır. Visual Studio projeyi bu dosyadan tanır.
2. 

GeoraphMap.Core
 (Çekirdek Katmanı)


Place.cs
: Mekan nesnesinin şablonudur. Bir mekanın Id (kimlik numarası), Name (adı) ve Location (haritadaki koordinatı/noktası) olduğunu belirtir.
3. 

GeoraphMap.Infrastructure
 (Altyapı Katmanı)


AppDbContext.cs
: C# kodları ile PostgreSQL veritabanı arasındaki köprüdür. Veritabanında Places adında bir tablo olacağını söyler.


Migrations/
: C# tarafında yazdığınız Place sınıfını PostgreSQL veritabanında gerçek bir SQL tablosuna dönüştüren otomatik hazırlanmış komut dosyalarıdır.
4. 

GeoraphMap.API
 (Dış Dünya Katmanı)


Program.cs
: Uygulama başladığında ilk çalışan ana açılış dosyasıdır. Veritabanı bağlantı dizesi, Swagger ve servis ayarları burada başlatılır.


Controllers/
: Dışarıdan gelen HTTP (GET, POST) isteklerini karşılayan kapıdır.
appsettings.json: Veritabanınızın kullanıcı adı, şifresi ve port bilgisini tutan gizli ayar dosyasıdır.
